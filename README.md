Documentacion del proyecto
Proyecto de Monitoreo Deportivo — Jiu-Jitsu Brasileño y Alimentación

Este proyecto es una aplicación web desarrollada bajo el patrón Modelo-Vista-Controlador (MVC) con Spring Boot. Su objetivo principal es ofrecer una plataforma para el seguimiento y monitoreo del rendimiento deportivo, enfocándose en practicantes de Jiu-Jitsu Brasileño y su alimentación.
La aplicación permite gestionar datos relacionados con entrenamientos, nutrición y progreso físico, ofreciendo una interfaz dinámica y fácil de usar gracias a las tecnologías de Spring Boot y Thymeleaf.

Entorno de Desarrollo
Spring Tool Suite (STS): Entorno principal para la programación, compilación y ejecución del proyecto Spring Boot.
Visual Studio Code: Utilizado para la edición de archivos estáticos (HTML, CSS, JS) y control de versiones con Git.

GitHub: Para la gestión del repositorio, control de cambios y colaboración en el desarrollo del proyecto.
